# 로블록스 수익화 구조 (초안)

원칙: **진행(전직의 서 · 사탄 장비 · 참 · 신화 스킬 · 탑 층 · 벽 돌파)은 절대 팔지 않는다.** 이 게임의 재미는 20층마다의 벽을 파밍으로 넘는 것이라, 파는 순간 구조가 무너진다. 파는 것은 편의 · 시간 단축(일일 한도 있음) · 외형이다.

## 1. 게임패스 (한 번 구매, 영구)
| 상품 | 효과 | 비고 |
|---|---|---|
| 자동 전투 팩 | 자동 반복 전투 · 자동 분해 규칙 슬롯 확장 | 편의. 전투력에 영향 없음 |
| 가방 확장 | 가방 +100칸 · 창고 +100칸 · 돌 보관 한도 +50 | 상한 있음 |
| 골드 +50% | 골드 획득 +50% (프리미엄과 중복 불가, 큰 쪽만) | 골드는 이미 2배 드랍이라 +50%로 제한 |
| 프리셋 확장 | 스킬 · 장비 · 패시브 프리셋 슬롯 +3 | 편의 |
| 스킬 도감 + 통계 | 상세 전투 로그 · 스킬별 피해 비중 표시 | 편의 |

## 2. 개발자 상품 (소모성, 반복 구매)
일일 구매 한도를 서버에서 건다 (한도 초과 시 구매 버튼 비활성).
| 상품 | 내용 | 일일 한도 |
|---|---|---|
| 강화석 꾸러미 | 강화석 일정량 (파밍 1~2시간 분량) | 5 |
| 재굴림 보호권 | 재굴림 실패 시 직전 값으로 되돌릴 수 있는 1회권 | 10 |
| 입장 열쇠 묶음 | 상위 보스 관문 열쇠 5개 (한 번에 1단계 분) | 3 |
| 오프라인 보상 x2 | 접속 종료 동안 쌓인 보상 2배 수령 (1회) | 3 |
| 소원의 구슬(결정론) | 지정 옵션 한 줄을 고정하고 다른 줄을 재굴림 | 3 |

**판매 금지:** 전직의 서, 사탄 장비, 참, 신화 스킬, 계시의 돌, 탑 클리어 · 층 이동, 전투력 직접 증가.
**랜덤 상품 주의:** 돈을 내고 무작위 결과를 얻는 상품은 Roblox 정책상 확률 공개가 필요하다. 위 목록은 전부 결정론으로 잡았다.

## 3. 프리미엄 혜택 (Roblox Premium 구독자)
- 일일 접속 보상 +50%, 골드 +10%, 전용 이름표 · 이펙트. 전투력 증가는 없음.

## 4. 외형 · 시즌
- 스킬 이펙트 스킨, 캐릭터 · 펫 외형, 탑 입장 연출, 길드 문장. (전투력 0)
- 시즌 패스(8주): 무료 보상 + 유료 보상(외형 · 편의 재화만). 진행 속도는 건드리지 않는다.

## 5. 서버 구현 체크리스트
1. `MarketplaceService.ProcessReceipt`: 구매 ID를 DataStore에 기록해 **중복 지급 방지(멱등)**. 지급 실패 시 `NotProcessedYet` 반환.
2. 일일 한도는 서버 시간(UTC 기준 날짜) + 플레이어 DataStore로 관리, 클라이언트 신뢰 금지.
3. 게임패스 소유는 `UserOwnsGamePassAsync` 결과를 접속 시 캐시하고 `PromptGamePassPurchaseFinished`로 갱신.
4. 상품 ID는 Studio에서 만든 뒤 `ServerStorage.Game.Monetization` 의 `PRODUCTS`/`PASSES` 에 채운다 (지금은 0 = 비활성).
5. 환불 · 분쟁 대비: 지급 로그(누가 언제 무엇을)를 남긴다.

## 6. 가격 가이드 (로벅스, 참고용 · 출시 후 조정)
패스 199~799 · 소모성 49~249 · 외형 99~499 · 시즌 패스 399. 첫 2주는 가격을 올리지 않고 구매 전환율을 본다.
