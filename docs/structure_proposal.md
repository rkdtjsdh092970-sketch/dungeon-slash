# Claude 제안 — 전체 구조안 (2026-11-04, 비교 · 검토용, 결정 아님)

사용자가 정한 것(장비 드랍 없음 · 강화 · 옵션 리롤 · 부위별 스탯 · 스킨, RNG 전환 안 함, 빌드형 장르 유지, 최소 25만 원 회수)을 바탕으로,
`problems.md` 의 문제들을 **한 구조 안에서** 같이 푸는 안. 보장된 정답이 아니라 시험해 볼 설계.

## 1. 한 줄 요약
**균열을 오르는 한 줄짜리 진행 + 성장 기둥 3개 + 재화 4종.** 잠수는 이미 깬 층에서 재료를 모으고, 새 층은 직접 민다.

## 2. 진행의 뼈대 (한 줄)
스테이지(액트 1~10, 튜토리얼 겸 스토리) → **균열 1~100층 (메인 진행)** → **대균열 101층~ (끝없음, 순위)**
- 새 층은 직접 깨야 열림. 잠수(자동 반복)는 깬 층에서만.
- 옆길 콘텐츠는 3개만: 보스 관문 · 탑 · 레이드. 각각 **대표 보상 하나**.
- 합치거나 빼는 콘텐츠: 신전 · 문지기 · 보물고 · 참 던전 · 상위 관문 → 위 3개에 흡수, 무한 균열 → 대균열.

## 3. 성장 기둥 3개
| 기둥 | 역할 | 내용 |
|---|---|---|
| **아르카나** | 빌드 = "무엇을 하는가" | 소환으로 얻고 중복으로 레벨업. 카드마다 **역할 표시**(단일 · 광역 · 후열 타격 · 장판 · 생존). 룬은 없애고 대신 ★단계마다 **눈에 보이는 변화**(투사체 +1, 범위 2배 등) |
| **장비** | "얼마나 센가" | 고정 8칸, 강화석으로 강화, 큐브로 옵션 리롤. 부위마다 성격(무기 = 공격, 갑옷 · 투구 = 생존, 장갑 = 치명, 장신구 = 특수). 강화 +10 · +20 · +30 … 마다 **옵션 줄 개방 · 스킨 변화**. 고유 장비 → **아주 낮은 확률의 특별 옵션**(예: 근접 공격 후열 관통). 소켓 돌 → 옵션에 흡수 |
| **캐릭터** | "영구 성장" | ① 작은 패시브 트리: 큰 선택(키스톤) 10~15개, 초기화 무료 = 전략 ② **골드 영구 강화**(공격 · 체력 · 행운 …): 끝없이 살 수 있고 갈수록 비쌈 = 로블록스식 "계속 강해짐" + 골드 소비처 + 잠수 의미 |

## 4. 재화 4종 (지금 약 6~8종)
| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 골드 | 균열(잠수 주력) | 영구 강화(끝없음) |
| 강화석 | 균열 · 일일 | 장비 강화 |
| 큐브(일반 · 상급) | 보스 관문 · 탑 · 레이드 | 옵션 리롤 (상급 = 좋은 옵션 확률↑) |
| 아르카나 조각 | 퀘스트 · 일일 · 첫 클리어 · 대균열 | 아르카나 소환 |
- 열쇠 · 혼돈 구슬 · 돌 · 룬 · 참 재료 없앰 (보스 관문은 하루 무료 입장 횟수로).

## 5. 콘텐츠별 대표 보상
| 콘텐츠 | 대표 보상 |
|---|---|
| 스테이지 | 기능 해금 · 첫 클리어 |
| 균열 | 골드 · 강화석 · 경험치 (잠수 주력) |
| 대균열 | 순위 · 칭호 · 아르카나 조각 |
| 보스 관문 | 큐브 |
| 탑 | 상급 큐브 · 줄 잠금 |
| 레이드 | 특별 옵션 확률이 높은 큐브 · 칭호 · 스킨 |

## 6. 강함 표시 (전투력 딜레마)
- 장비가 고정이라 **장비 레벨(강화 단계 평균)** 이 강함의 큰 줄기를 정확히 나타냄 → 콘텐츠 권장은 "권장 장비 레벨 +15" (로스트아크 아이템 레벨 방식). "왜 못 깨?"의 범위가 아르카나 · 빌드 차이로 좁아짐.
- 자랑용 큰 숫자 = **허수아비 실측 피해량**(1M → 1B). "때리는 힘"이라고 밝힘.
- 순위 = **대균열 최고 층 + 시간** (상한 없음).
- 옵션 · 강화 비교 = 바뀌는 스탯을 ▲▼로.

## 7. 잠수
- 깬 층 반복 → 골드 · 강화석. 골드는 끝없는 영구 강화로, 비용이 오르므로 24시간 잠수해도 "조금 더" 강해질 뿐.
- 자동 리롤: 잠수 중 모인 큐브로 목표 옵션까지 굴려 **미리보기 대기열**에 쌓음 → 돌아와서 유지 / 교체 (나빠지는 일 없음, 전투 중 옵션 안 바뀜).
- 잠수 결과 요약 한 장.

## 8. 후열 문제
- 아르카나 역할 표시 + 직업마다 초반에 후열 타격 하나 보장 + 층 특징 표시("후열 많음") + 특별 옵션(후열 관통).

## 9. 처음 10분 · 해금 순서
전투 → 소환 · 장착 → 강화 → (레벨 10) 패시브 → (균열 10) 영구 강화 → (균열 20) 옵션 리롤 · 보스 관문 → (균열 50) 탑 → (균열 100) 레이드 · 대균열.
화면 한쪽에 항상 **"다음 할 일" 한 줄**.

## 10. 뽑기 두 개 → 하나처럼
아르카나 소환과 옵션 리롤을 **"뽑기" 화면 하나, 같은 규칙**(미리보기 · 자동 · 목표에서 멈춤 · 희귀 연출 · 행운 적용).

## 11. 수익 (25만 원 목표와 연결)
- 게임패스 후보: 자동 리롤 · 배속 · 추가 프리셋 · 행운 물약. 잠수 체류 → 프리미엄 페이아웃.

## 13. 솔직한 한계
- 시험 전엔 더 낫다고 보장 못 함. 작업량이 큼(장비 · 콘텐츠 정리, 세이브 환급, 로블록스 동시 반영).
- 장비 줍는 설렘이 사라짐 → 리롤 · 소환 · 스킨 변화로 채워지는지는 테스트로 확인.
- 콘텐츠를 줄이면 이미 만든 것(신전 · 참 던전 등)을 버리게 됨.
