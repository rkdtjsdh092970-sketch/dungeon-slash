# 방향을 찾는 방법 · 문제별 선택지 (2026-11-04, 결정 아님 — 고를 거리)

문제 목록은 `problems.md`. 여기는 "정답을 모를 때 길을 찾는 방법"과, 문제마다 다른 게임들이 쓴 선택지를 모은 것.
판단 기준: 최소 25만 원 회수 · RNG 전환 안 함 · 빌드 짜는 장르 유지.

## A. 정답을 모를 때 길을 찾는 방법
1. **기준 게임을 하나 정하고 따라가기** — 우리와 구조가 가장 비슷한 게임이 각 문제를 어떻게 풀었는지 보고 가져올지 말지만 정한다. 처음부터 새로 생각하는 것보다 빠르고 검증돼 있음.
   - 디아블로 3: 균열 · 대균열(층 + 시간 순위) · 파라곤(만렙 후 무한 영구 성장) · 피해/강인함/회복 3수치 · 자동 분해 — 우리 구조와 가장 가까움.
   - Dungeon Quest (로블록스): 던전마다 레벨 제한 · 시간 제한 · 난이도 5단계(노멀~하드코어), 어려운 난이도에서 좋은 능력 → 로블록스식 단순한 루트 RPG.
   - Pixel Lineage · Arcane Lineage (로블록스): 일부러 어렵게 만든 게임도 동접 수천~1만대 → 하드코어 틈새가 있음.
2. **빼 보기 실험** — 시험판에서 시스템 하나(예: 돌)를 꺼 보고 재미가 줄었는지 테스터에게 묻는다. 안 줄었으면 빼는 쪽.
3. **처음 10분 관찰** — 처음 하는 사람(테스터 · 지인)이 하는 걸 보며 어디서 멈추는지 적는다. 질문보다 관찰이 정확.
4. **숫자로 확인** — 시뮬 도구(균열 · 모르가스 · 성장 봇)로 바꾼 뒤를 미리 잰다. 이미 있음.
5. **작게 내보고 수치 보기** — 정지 풀린 뒤 소수 유입으로 다음 날 재방문 · 플레이 시간 · 결제를 본다.

## ★ 사용자 제안 방향 후보 (11-04): 장비 드랍을 없애고 강화 재료를 많이 준다
- 장비는 드랍되지 않음. 강화 재료를 많이 줌. **아주 낮은 확률로 뽑히는 옵션**을 만들고, 장비를 강화시키는 것이 목표.
- 푸는 문제: 장비가 쌓임 · 확인 노동 없음 / 잠수 보상이 늘 의미 있음(재료는 계속 쓰임) / 재료 → 강화 비용 곡선으로 잠수 밸런스 조절 / 장비 숫자 상한을 우리가 정함(인플레 조절) / 옵션 선별이 "여러 장비 비교"에서 "내 장비 하나 다듬기"로 단순해짐 / 낮은 확률 옵션 = 로블록스 유저가 좋아하는 뽑기 설렘 (RNG 전환 없이)
- 새로 생기는 문제 · 정할 것:
  - 장비 줍는 설렘이 사라짐 → 대신 옵션 뽑기 설렘으로 대체되는지
  - 지금 장비 쪽 시스템 정리: 티어(T1~T5) · 고유 장비 · 소켓 돌 · 프리셋 · 가방 · 창고 · 자동 분해 · +0 비교 중 무엇이 남나
  - 콘텐츠마다 무엇을 주나 (모두 같은 재료면 콘텐츠 구분이 흐려짐 → 콘텐츠별 다른 재료 · 옵션 뽑기권?)
  - 고유 장비(빌드를 바꾸는 효과)를 남길지
  - 강화 실패 · 단계 상한 · 비용 곡선
  - 옵션 뽑기 확률표 (최상 옵션이 얼마나 드물지)
  - 기존 테스터 세이브: 장비 → 재료 환급
  - (사용자 걱정) 옵션 굴리기를 자동으로 하면 던전 중에도 옵션이 계속 바뀌어 약해지고, 전략 요소가 다 사라지지 않나?
    - 흔한 처리: 새 옵션은 "미리보기 → 유지 / 교체"를 고름(나빠지면 안 바뀜) · 자동 굴리기는 목표 옵션이 나오면 멈춤 · 원하는 줄 잠그기(잠글수록 비쌈) · 전투 중엔 굴리기 불가
    - (사용자 걱정 2) 그러면 다들 마을에서 하루 종일 옵션만 굴리지 않나?
      - 굴리는 재료는 전투에서만 나오게 → 굴리다 재료가 떨어지면 다시 싸우러 감 (싸움 ↔ 굴리기 반복)
      - 굴리기를 어디서나(전투 중 메뉴) 할 수 있게 하고, 결과는 다음 판 시작부터 적용 → 마을에 붙잡혀 있을 필요 없음
      - 자동 굴리기를 잠수와 묶음: 잠수 중에 모인 재료로 목표 옵션까지 알아서 굴려 둠 (미리보기 대기열에 쌓고 돌아와서 고름)
    - 전략은 "어떤 옵션을 노릴지 · 어느 줄을 잠글지 · 재료를 강화에 쓸지 옵션에 쓸지"로 남음
- 콘텐츠마다 무엇을 주나 (선택지):
  - ① **콘텐츠 하나 = 대표 보상 하나** (디아블로 3: 대균열 = 보석 강화, 현상금 = 제작 재료, 각 콘텐츠의 역할이 분명). 예시(결정 아님):
    | 콘텐츠 | 대표 보상 |
    |---|---|
    | 스테이지(스토리) | 새 기능 해금 · 첫 클리어 보상 |
    | 균열 (잠수 주력) | 강화 재료 · 경험치 |
    | 보스 관문 | 옵션 굴리기 재료 |
    | 탑 | 잠금 재료 · 상급 굴리기 재료(좋은 옵션 확률↑) |
    | 레이드 · 모르가스 | 고유 효과(빌드를 바꾸는 옵션) · 칭호 · 스킨 |
    | 무한 균열(대균열) | 순위 · 칭호 · 영구 포인트 |
    | 일일 · 퀘스트 | 굴리기 재료 소량 · 아르카나 조각 |
  - ② 모든 콘텐츠가 같은 재료, 효율만 다름 → 단순하지만 "어디 가든 똑같다"가 되어 콘텐츠가 흐려짐
  - ③ 섞기: 강화 재료는 어디서나 조금씩, 나머지는 ①처럼 콘텐츠 전용
- (사용자 걱정 3) 아르카나도 뽑아야 하고 장비 옵션도 굴려야 함 → 뽑기가 두 개 = 다시 복잡
  - ① 뽑기는 아르카나 하나만: 장비는 강화만(옵션 없음 또는 고정 옵션) → 가장 단순
  - ② 뽑기는 장비 옵션 하나만: 아르카나는 진행(층 · 보스)으로 해금 · 레벨업
  - ③ 둘 다 두되 재료 · 화면 · 방식 통일: "뽑기" 화면 하나에 탭 두 개, 같은 재료(또는 같은 규칙: 미리보기 · 자동 · 목표에서 멈춤) → Roll A Stickman 도 롤 · 특성 재굴림 · 펫이 같은 방식이라 여러 개여도 덜 복잡함
- 비슷한 방식: 메이플스토리 잠재능력(큐브로 옵션 재설정), 많은 로블록스 · 모바일 성장 게임의 "고정 장비 + 강화"

## B. 문제별 선택지 (다른 게임들이 쓴 방식)

### 전투력
- ① 지금처럼 숫자 하나 (부정확 · "왜 못 깨?" 문제 유지)
- ② 디아블로 3식 3수치: 피해 · 생존 · 회복. 장비 · 룬 · 돌 · 패시브 비교를 "피해 +6%, 생존 −2%"로. 권장도 두 숫자 → 무엇이 모자란지 보임
- ③ 숫자 없이 Dungeon Quest식 레벨 제한 + 난이도 단계
- 자랑용 큰 숫자는 별도로: 허수아비 실측 피해량(1M→1B), 순위는 층 + 시간

### 패시브
- ① 디아블로 3 파라곤식: 지금 트리는 작게 두고, 레벨 상한 뒤 **무한히 쌓이는 영구 포인트**(작은 스탯) → 로블록스식 "계속 강해지는 느낌" + 전략 일부 유지
- ② 로블록스식 완전 영구 강화: 골드로 사는 영구 스탯 → 직관적, **골드 소비처 문제도 같이 해결**
- ③ 갈래를 적게 · 선택을 크게: 노드 수를 줄이고 몇 개의 큰 선택(키스톤)만 → 전략은 남고 머리는 덜 아픔

### 아르카나 룬
- ① 없애고 아르카나 레벨에 흡수
- ② 남기되 효과를 숫자로 표시 (끼면 "쿨타임 4.0 → 3.4초")
- ③ % 대신 **눈에 보이는 변화**로 바꿈 (예: 투사체 3갈래, 범위 2배) → 존재감 · 체감

### 돌(소켓)
- ① 없애고 환급
- ② 종류를 크게 줄여 3수치(피해 · 생존 · 회복) 중 하나에만 들어가게
- ③ 후반(균열 이후)에만 열기

### 아르카나 역할 (후열)
- ① 카드에 역할 표시 (단일 · 광역 · 후열 타격 · 관통 · 장판 · 생존) + 직업마다 초반 후열 타격 하나 보장
- ② 몬스터 쪽 해결: 원거리 몬스터가 일정 시간 뒤 앞으로 나옴
- ③ 층 특징 표시 ("후열 많음") → 막힌 이유가 보임

### 잠수 장비 쌓임
- ① 자동 분해 규칙(등급 · 티어 기준) — 높은 등급은 자동 분해 제외가 보통 (Leaf Blower Revolution 사례)
- ② 루트 필터: 플레이어가 "가질 것 / 분해할 것" 규칙을 정함 (디아블로 4 · PoE)
- ③ 장비가 아니라 재료로 떨어지게: 잠수 중엔 장비 대신 분해 결과물만
- ④ 잠수 보상 상한 · 시간이 갈수록 감소

### 하루 종일 잠수하는 사람의 밸런스
- ① 진행은 직접만: 잠수는 이미 깬 곳만 반복 → 새 층 · 보스는 직접 해야 함. 잠수가 아무리 길어도 "진행"은 안 앞질러감
- ② 갈수록 비싸지는 소비처: 영구 강화 비용이 계속 올라가게 → 24시간 잠수해도 몇 시간 잠수보다 "조금 더" 강해질 뿐 (시간에 정비례하지 않음)
- ③ 시간당 효율 감소: 오래 켤수록 잠수 보상이 줄어듦 (피로도) · 하루 상한
- ④ 기준 플레이어를 정하고 맞추기: 예) "하루 직접 1시간 + 잠수 몇 시간" 인 사람이 목표 속도가 되게 표를 만들고, 그 이상은 ②③으로 완만하게
- ⑤ 잠수러가 더 센 건 허용: 로블록스에선 잠수 = 수입원(프리미엄 체류 시간). 순위는 층 + 시간(직접 플레이)이라 잠수만으로 1등은 못 하게
- 보통은 ① + ② 조합이 기본 (방치형 게임 공통)

### 장비 확인이 노동이 되는 문제
- 장르 공통 관찰: 장비 확인이 재밌는 건 **드물고 의미 있을 때**(드디어 나온 한 개). 많이 쏟아지면 노동.
- ① 적게 · 더 좋게 떨구기: 디아블로 3 "루트 2.0" — 드랍 수를 크게 줄이고 내 직업에 맞는 옵션이 더 잘 붙게
- ② 게임이 대신 확인: 지금 것보다 좋은 것만 남기고 나머지는 자동 분해, "업그레이드 2개 발견"처럼 좋은 것만 알림
- ③ 잠수 결과 요약 한 장: "3시간 동안: 업그레이드 2 · 분해 340개 → 강화석 +X" — 하나씩 볼 필요 없음
- ④ 좋은 게 나왔을 때만 연출: 최상급 · 고유 장비는 크게 터뜨리고, 나머지는 조용히
- ⑤ 자동 착용(선택): 확실히 좋은 건 알아서 낌

### 재화 지급 속도
- ① 재화 종류부터 줄이기 (적을수록 속도 정하기 쉬움)
- ② 시간당 "들어오는 양 / 쓰는 양" 표를 먼저 정하고 그 표에 맞춰 드랍 조정 (시뮬로 확인)
- ③ 끝없이 쓸 수 있는 소비처 하나 두기 (패시브 ②, +10 이후 강화 등) → 남아돎 방지

### 높은 난이도 보상 (무엇을 줄까)
- ① 더 강한 장비 (지금 방식) — 장비 상한이 없으면 숫자가 끝없이 커지고 콘텐츠도 계속 더 어렵게 만들어야 함 (파워 인플레)
- ② 디아블로 3식 "상한 있는 장비 + 확률": 장비 강함엔 끝(T5)이 있고, 높은 난이도는 **좋은 옵션 · 고대/태고 같은 최상급이 나올 확률**을 올림 → 같은 장비를 더 좋게 다듬는 재미
- ③ 성장 속도로 보상: 경험치 · 영구 포인트(파라곤) · 재료를 더 많이 → 장비 숫자는 안 커짐
- ④ 빌드를 바꾸는 장비: 더 센 게 아니라 **새 효과**(예: 근접 공격이 뒷줄까지 관통)를 주는 고유 장비 → 빌드 다양성 · 후열 문제와 연결
- ⑤ 자랑용 보상(로블록스에서 강함): 칭호 · 이름 색 · 오라 · 아르카나 연출 스킨 · 순위 → 강함을 안 늘리면서 우월감
- 보통은 섞어 씀: 예) 장비는 T5 에서 멈춤 + 높을수록 최상급 확률 ② + 영구 포인트 ③ + 일정 층마다 칭호 · 스킨 ⑤

### 잠수의 이득 (잠수로 무엇을 얻게 할까)
- 참고: 로블록스는 프리미엄 회원이 머문 시간만큼 개발자에게 돈을 줌 → 잠수는 막을 대상이 아니라 **수입원**. 문제는 잠수할 이유가 약하다는 것.
- ① 잠수 = 영구 성장 공장: 잠수로 모은 것이 끝없이 쓰이는 곳(영구 패시브 · 파라곤)으로 들어감 → 오래 켜 둘수록 확실히 강해짐
- ② 잠수는 "재료", 직접 플레이는 "진행": 새 층 · 보스 · 첫 클리어 보상은 직접, 잠수는 꾸준한 재료만 → 역할이 분명
- ③ 잠수 전용 콘텐츠: 원정 · 파견처럼 보내 놓고 나중에 받기 (Roll A Stickman 의 Expeditions 탭)
- ④ 잠수 중 희귀 확률: 오래 돌수록 아주 낮은 확률로 최상급 장비 · 스킨 → 켜 둘 이유(기대감)
- ⑤ 잠수 시간 자체 보상: 접속 시간 보상 상자 · 칭호
- 지금 문제(골드 · 조각만 남아돎)는 "쓸 곳" 문제와 같은 뿌리 → 소비처 ①과 같이 정해야 함

### 진행 구조 (흐릿함)
- ① 디아블로 3식 한 줄: 스테이지(스토리) → 균열(난이도) → 대균열(무한 층 · 순위). 나머지 콘텐츠는 이 줄의 보조
- ② Dungeon Quest식: 던전 여러 개 × 난이도 단계, 레벨 제한으로 순서가 정해짐
- ③ 기둥 3개(장비 · 아르카나 · 캐릭터)로 묶고 콘텐츠마다 어느 기둥을 올리는지 하나씩
