# 전직 · 레이드 · 참 · 상위 보스관문 설계 요청 (2026-11-01, 사용자 요청 원문 정리)

(원본: 프로젝트 문서 `claude/class-raid-charm-design.md`. 구현은 완료되어 `docs/tower-design.md`에 현황이 있다.)

## 진행 방식 (사용자 지시)
1. 밸런스 시뮬레이터로 충분히 데이터를 쌓는다 → 2. 적정선을 찾아 문제를 해결 → 3. 밸런스 패치 배포 → 4. 이후 다른 내용은 사용자 허락 없이 순차 배포. 단 **참 고유 옵션 목록은 아이템 생성 전에 사용자 확인**.
- 시뮬 도구는 `/tmp/bal/v4`(세션 임시). /tmp이 비면 소스(`source/src`)에서 하네스를 다시 만든다 (`source/test/simlib.js`).

## A. 밸런스 패치
1. 물리 빌드 전용 패시브 트리: 물리 관통 · 물리 저항 무시 중심. 2. 룬 소켓: 매직 1, 레어 최대 2. 3. 옵션 티어별 수치 소폭 조정(6티어 하향도 좋음).

## B. 레이드 던전 (이지 / 노말 / 하드)
- 이지: 솟아난 탑 30층 스펙 → 드랍 전직의 서 → 1차 전직. 노말: 탑 80층 난이도 → 2차 전직, 상위 보스관문 개방. 하드: T6 장비 2등급 이상 4유효 장비 + 계시의 돌 풀 장착 → 3차 전직, 참 던전 입장권, 새 탑 개방.
- 탑 100층: 2차 전직 + 계시의 돌 풀 장착 + 최소 풀 2티어 이상 4유효 장비로 클리어 가능한 난이도. 클리어 시 T6 전설/사탄 드랍.

## C. 전직 · 전직 패시브
- 전직 시 일반 패시브와 별개의 **전직 포인트 2점**. 속성별 + 방어 + 파밍 7트리(화염·냉기·번개·공허·물리&독·방어·파밍), 서로 겹치지 않게 배치. 포인트가 적은 만큼 노드 하나하나가 강력해야 함.

## D. 상위 보스관문
- 노말 레이드 클리어 시 개방. 드랍: 사탄 스킬 · 종말 스킬. 입장 재료: 하위 보스관문 입장 키 ×5. 탑에서도 키 드랍.

## E. 참(Charm)
- 3차 전직 후 장비칸 아래 4줄 슬롯. 하드 레이드 난이도의 참 던전에서 드랍. 옵션은 고유 옵션식(참고 poe2db 고유 아이템, 2줄 정도를 던전슬래시에 맞게 수정). 전투력 상승은 약 30%, 파밍 편의·생존·유틸 위주. 아이템 생성 전 옵션 목록 사용자 확인.

## F. 새 문지기 보스
- 모르가스와 비슷하지만 새 패턴, 유저가 직접 참여하는 형식. 전투력 측정기(참 파밍까지 마친 스펙 조건).

## G. 하드 레이드 클리어 후
- 새로운 탑 개설.
