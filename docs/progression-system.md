# 성장 시스템 기획 메모 (레벨업 / 특성)

최종 갱신: 2026-10-27 (원본: 프로젝트 문서 `claude/progression-system.md`. **현재 구현은 소스/`docs/game-v3-changelog.md`·`docs/tower-design.md`가 우선**)

## 확정 (사용자가 직접 정함)
- 무리 칸의 **기본 칸당 마리 수는 2~3마리**로 시작. 증가는 장비 옵션과 특성으로
- 특성 시스템은 **특정 레벨 이후 열리는 PoE 같은 패시브 트리**. 단, PoE처럼 깊게 하지는 않음
- **클래스는 여러 개**
- **100레벨 이후에는 레벨업 자체보다 장비와 스킬 파밍**을 하며 천천히 진행
- 10액트 × 10스테이지 → (현재 구현은 액트 1개 + 균열 100층 구조로 바뀜. `docs/game-v3-changelog.md`/`roblox/HANDOFF.md` 참고)
- 액트 전부 클리어 후 영구 2레인(이후 3레인으로 조정됨)

## 고민 중
- **4인 스쿼드**(한 사람이 캐릭터 4명 편성): 나중에 다시 고민. 영향 규칙: 아군 배치, 적 공격 대상 선택, 스킬 4칸 구조, 체력 공유, 캐릭터별 레벨·트리. 추천: 솔로 핵심 재미를 먼저 검증하고 스쿼드는 확장으로

## 임시 확정 (Claude 추천 기본값)
- 레벨 상한 100, 레벨당 완만한 증가(레벨 100에서 약 5배). 100레벨 이후 레벨업 불가, 성장은 장비/스킬 파밍
- 패시브 트리: 소규모로 시작해 구조 검증 후 확장 (현재 구현은 245노드 규모로 확장됨)
- 리스펙 가능(골드)
- 트리 노드 종류: 칸당 마리 수, 레인, 스킬 쿨타임/범위/사거리, 회피·방어, 대상별 추가 피해, 광역 강화
- 키스톤: 레인/밀도 같은 파밍 효율 효과는 키스톤으로 제한하고 위험-보상 구조

## 미정
- 4인 스쿼드 도입 여부, 클래스별 스킬 풀(현재는 전직 7트리로 구현됨, `docs/tower-design.md`)
