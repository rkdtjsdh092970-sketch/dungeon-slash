# Dungeon Slash — 구현 현황 (10/28 시점, 원본: 프로젝트 문서 `claude/game-v2-design.md`)
※ 구버전 정보 포함(예: "액트 10개", 패시브 120노드는 이후 바뀜). 현재 값은 소스가 우선. 요약 위주로 옮김.

## 배포 / 소스
- 접속 주소: https://dungeon-slash.jjy1.workers.dev (Cloudflare Worker가 GitHub의 `index.html`을 서비스). 소스 저장소 https://github.com/rkdtjsdh092970-sketch/dungeon-slash (공개), `source/`에 src·template·build.py·server·test·art 전부.
- 빌드 `python3 source/build.py` → `dist/game.html`. 배포는 루트 `index.html`, `ver.txt`로 복사 후 push. 접속 중 사용자에게 1분 안에 "업데이트하기" 배너(`/api/ver`).
- 모듈 순서: util, data, data2~5, state, battle, battle2, assets, audio, render, render2, ui, ui2~5, main. 엔진(data/state/battle/battle2)은 DOM 비의존.
- 서버: Cloudflare Worker + D1. 브라우저 기본 대화상자(confirm 등)가 게시 환경에서 막히므로 자체 확인창(`askConfirm`)만 사용.

## 화면 / UI 규칙
- **업데이트 게시판**: 마을의 '업데이트 게시판'(src/notes.js `PATCH_NOTES`)에 업데이트마다 맨 위에 항목 추가.
- 타이틀 → 튜토리얼 → 마을 → 월드맵 → 전투 → 결과. 단축키 M 지도, I 장비, K 스킬, P 패시브, C 스탯, Q 퀘스트, D 도감, T 일일, R 기록.
- 장비 창: ▲ 표시, 추천 장착, 프리셋 3칸, 잠금, 필터/정렬, 일괄 정리. 스탯 창, 스킬 카드, 도감, 일일 목표, 오프라인 보상.
- **노드 겹침 금지**(맵·패시브). `test/overlap.js`로 검사.

## 전투 / 데미지 공식 (밸런스 핵심 축)
- 피해 = (공격력×PHYS_BASE 1.22 또는 주문력×MAG_BASE 0.95) × 스킬배율 × (1+주는피해+종류피해+원소피해%) × 대상 보너스(보스/정예/원거리/일반) × 방어/저항 감소 × 속성 저항 × 치명.
- 방어 감소율 = X/(X+DEF_C 8), X = 적 계수 × (1+DEF_ACT 0.18×(액트-1)) × (1+DEF_TIER 0.03×균열단계) × (1-방어무시) × (1-파쇄). 물리는 방어력, 마법은 마법저항. 속성 저항은 액트별(ACT_ELEM)에서 관통을 뺌.
- 치명: 물리 critChance, 마법 spellCrit. 원소: 화염/냉기/번개/공허.
- 마나: 모든 스킬이 마나 소모(기본공격 무료). 최대 마나 100×(1+%)×레벨계수, 재생 0.08/초. 마나→주문력, 마나 방패, 마나당 피해, 처치 시 마나 지원.
- 상태이상: 출혈(물리, .6·4초·8중첩), 중독(물리/공허, 1.7·5초·20중첩), 점화(화염, .55·3초). 보스 ×0.5, 정예 ×0.8 지속피해 감소.
- 스킬 레벨 최대 20(연마석), 룬, 시련의 탑 노드.

## 장비 / 고유
- 부위 8칸: 무기·투구·갑옷·장갑·신발·반지·목걸이. 아이템 레벨별 옵션 티어. 고유 약 87종, 등급 미스틱→이터널→소버린→엔젤릭, 출처별 풀. 공허의 군주는 6개 중 1개 선택.
- 드랍: MF 체감 mfEff = mf/(1+mf/MF_HALF 6). MF는 수량이 아니라 등급/고유 확률에만 영향. 구슬(혼돈/신성), 대장간 강화, 분해, 옵션 재굴림.

## 패시브 / 엔드게임
- PoE식 방사형 트리(이후 245노드 이상으로 확장), 인접 노드 활성화 필요, 연결이 끊기지 않을 때만 회수.
- 엔드게임: 영구 3레인, 심연의 균열, 무한 균열, 공허의 군주, 지옥 스테이지, 월드 버프, 심연 각인, 스킬 파밍.

## 온라인 (Cloudflare)
- 경매장(골드 거래, 수수료 5%, 3일 만료), 길드(생성 20,000G/가입/탈퇴/기부/공지/채팅/랭킹, 길드 레벨 보너스). 로블록스 이식에서는 경매장 제외, 길드는 개선해서 이식.
