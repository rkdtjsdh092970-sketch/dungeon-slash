# 기획 문서 목차

원래 claude.ai 프로젝트 "게임 기획"에 있던 문서를 저장소로 옮겼다. 일부는 요약/주석을 붙여 옮겼고, **구버전 내용은 소스(`source/src`)와 `roblox/HANDOFF.md`가 우선**이다.

| 문서 | 내용 | 최신성 |
|---|---|---|
| `combat-system.md` | 전투 규칙(레인·열·무리 칸·타겟팅·추가 피해 곱연산) | 핵심 규칙은 유효 |
| `progression-system.md` | 레벨·패시브·클래스 방향, 4인 스쿼드(보류) | 일부 구버전 |
| `content-design.md` | 초기 액트·장비·스킬 설계 | 구버전 (현재 수치는 소스) |
| `world-map-town.md` | 월드맵·마을·퀘스트 초기 기획 | 구버전 |
| `game-v2-design.md`, `game-v2-changelog.md`, `game-v3-changelog.md` | v1~v3 구현 현황·작업 규칙·서버 구조 | 인수인계에 유용 |
| `tower-design.md` | 솟아난 탑·레이드·전직·참 (v4.46) + 밸런스 시뮬 근거 | 최신 |
| `class-raid-charm-design.md` | 전직·레이드·참 요청 원문 정리 | 구현 완료 |

옮기지 않은 것: 사탄 장비 한 줄 풀 82종(`source/src/satan.js`에 구현됨), 초기 Godot 프로토타입 코드 조각, 구 도트 그래픽 사양(`source/art/`가 원본), 로블록스 현황(`roblox/HANDOFF.md`가 최신). 필요하면 사용자에게 요청한다.
