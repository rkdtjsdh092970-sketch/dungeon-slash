# 월드맵 · 마을 · 퀘스트 · 스킬 칸 해금 기획 (원본: 프로젝트 문서 `claude/world-map-town.md`, 2026-10-27)
※ 초기 기획. 현재 구현은 액트 1개 + 균열 100층 구조로 바뀜(`roblox/HANDOFF.md`). 참고용.

## 사용자가 정한 것
- 스킬 칸 해금: 1번(기본공격) 시작부터, 튜토리얼 후 2번, 3액트 보스 처치 3번, 6액트 보스 처치 4번 (현재 구현: 스테이지 3/5 클리어 시 3·4번 칸)
- 맵은 한 장의 월드맵(노드가 길로 연결, 자물쇠/구슬/해골 아이콘, 노드 옆 숫자는 권장 레벨)
- 액트마다 마을: 한 화면에 강화·스킬 정비·경매소·길드 오브젝트. 경매소는 보류(로블록스에서는 제외)
- 마을 안 퀘스트: 받으면 퀘스트 UI에 추가

## 마을 설계 (임시 추천)
- 스킬 정비소(장착, 타겟 규칙), 대장간(강화·분해·재굴림), 창고·상점, 퀘스트 게시판, 길드, 훈련소(패시브 트리).
- 마을 기능은 액트가 진행될수록 점차 해금.

## 퀘스트
- 상태: 수락 가능 → 진행 중 → 완료 → 수령 완료. 종류: 메인/서브/일일. 목표: 몹 처치, 스테이지·보스 클리어, 아이템 수집. 보상: 경험치, 골드, 장비, 스킬, 재료.
