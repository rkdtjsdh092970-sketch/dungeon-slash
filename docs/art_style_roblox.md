# 로블록스에서 통할 화풍 조사 (2026-11-04, 웹 검색 + Codex 의견)

## 1. 조사 결과 — 비슷한 성공 사례
- 어두운 2D 고해상도 도트로 크게 성공한 로블록스 게임은 **찾지 못함** (불가능하다는 뜻이 아니라 선례가 없음).
- 다크 판타지 분위기: **Deepwoken** (방문 11억+). 단 3D · 자기 아바타 · 나이 있는 층.
- 화면(UI) 중심 카드 뽑기 · 성장: **Anime Card Clash** (방문 약 4.5억, 동시접속 수천~1만대, 외부 집계). 그림은 밝은 애니풍 + 깔끔한 수집 화면.
- 2D 도트 게임 (2D PIXEL RPG · Build a Pixel Art): 평가 수천~1만 개 수준, 큰 흥행은 아님.

## 2. 로블록스에서 통하기 쉬운 그림의 공통점
- **실루엣이 먼저 읽힌다**: 머리 · 무기 · 몸통 형태만으로 아군 / 적 종류 구분.
- **눈이 가는 순서가 분명**: 캐릭터 → 공격 신호 → 배경.
- **성장 보상이 큼직하게 보인다**: 희귀 카드 · 장비 교체 · 승급 연출.
- **화면 전체 통일감**: 도트냐 애니냐보다 섞이지 않는 게 중요.
- 유아틱하지 않게: 잔혹함 대신 **각진 형태 · 절제된 표정 · 갑옷과 문양 · 무게감 있는 동작**.

## 3. 지금 그림을 살리면서 가독성 올리는 규칙 (Codex 제안, 수치는 시작값)
- **색 역할 나누기**: 배경 = 먹색 · 청회색 / 아군 = 청록 · 상아색 / 적 = 주황 · 자주 계열. **빨강은 위험 신호와 용암 포인트에만**. 용암은 갈라진 틈만 빛나게.
- **색 말고도 구분**: 아군 원형 발판, 적 각진 발판, 체력바 모양 · 진영 표식.
- **외곽선**: 캐릭터 어두운 외곽선 + 배경과 겹치는 쪽 밝은 테두리, 화면 표시 기준 1~2px.
- **명암**: 흑백으로 바꿔도 배경과 몸통이 분리되어야 함. 세부 묘사보다 큰 명암 덩어리.
- **배경**: 전투 줄 뒤 해골 · 불꽃 · 균열 무늬를 줄이고 대비를 낮춤 (흐림보다 색 단계 줄이기).
- **크기**: 눈 · 무기 · 뿔 같은 식별 요소를 키움. 목록에는 전신 대신 흉상 아이콘.
- **이펙트**: 화면 전체 붉은 빛 · 플래시 줄이고, 짧은 궤적 + 피격 표시. 캐릭터 윤곽을 가리지 않게.
- **약관**: 악마 · 해골은 뿔 · 가면 · 뼈 실루엣으로. 피 · 상처 · 살점 없이, 처치는 연기 · 룬 · 빛 입자로. **피를 다른 색으로만 바꾸는 건 피할 것.**

## 4. 썸네일 · 아이콘
- 아이콘: 영웅 하나 또는 아르카나 카드 하나를 크게. 512×512 로 만들고 **150×150 으로 줄여 확인** (폰 탐색 화면은 약 110px).
- 썸네일: 한 장에 한 메시지 (카드 획득 / 장비 성장 / 균열 보스 중 하나). 풍경보다 캐릭터 얼굴 · 동작.
- 실제 게임에 있는 캐릭터 · 보상만 쓰기 (GUI 게임인데 3D 액션처럼 보이게 하면 이탈).
- 확인 방법: 폰 실제 크기 · 흑백 · 이펙트 최대 상태에서 처음 보는 사람이 아군 / 적 / 공격 대상을 바로 짚는지.

## 6. 샘플 비교 결과 (`style_roblox/compare_phone.png`: 폰 크기 400px · 흑백)
- 지금 화면: 흑백에서 몬스터 · 플레이어가 배경에 묻혀 **구분 불가** (가장 나쁨).
- A 정돈된 다크 도트: 흑백에서도 7명 모두 구분, 지금 분위기 유지 → **1순위 추천** (기존 그림 재사용 가능).
- C 손그림풍: 가장 잘 읽힘. 다만 고블린 등이 귀여운 쪽이라 '유아틱 금지'와 경계선.
- B 애니 가챠풍: 화려하지만 이펙트 · 배경이 복잡해 작게 보면 산만함.
- D 아바타풍: 몬스터가 작고 어두워 묻힘, 2D 게임과 어색.
- 주의: 한 장짜리 일러스트 비교임. 실제 게임은 배경 + 몬스터 그림 수백 장이라 **화풍 통일 유지**가 더 큰 과제.
